VisualLink

Project Description

VisualLink is a software project that allows users to control their computers by tracking head movement via a webcam. Won 1st place at SacHacks VI: Best Technical Implementaiton, Best Overall Hack

Implementation

Visual Link uses Python, OpenCV, and Google MediaPipe

Impact

Made for users with mobility impairments to use technology by supporting mouse movement and voice to text typing system
