RateMyDiningHall

Project Description

RateMyDiningHall is a web application designed to help UC San Diego students review and discover campus dining options

Implementation

The project uses React, TypeScript, GraphQL, and MongoDB to manage dining hall information and reviews

Impact

The application aims to make dining information easier for students to access and compare based on their dietary needs
